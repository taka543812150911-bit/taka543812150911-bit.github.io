プライバシーポリシー

対象：副業・脱サラ計画 YouTube履歴保存

取得する情報と利用目的

本ツールはYouTube APIサービスを利用します。利用者本人が許可したチャンネルのID・名称・URL・登録者数・累計再生数・公開動画数と取得日時を扱い、本人の実績確認と履歴管理のために使用します。取得値から入金額を推定しません。

保存先と共有

取得した実績は本人がアクセスを許可したNotionへ保存します。API通信・定期実行にはGoogle Apps Scriptを使用するため、GoogleとNotionの各サービスで情報が処理されます。実績を広告配信、販売、AIモデルの学習には利用しません。認証情報や取得した記録をこの説明サイトや公開リポジトリに掲載しません。

OAuthの更新トークン、クライアントの秘密情報、Notionの接続トークンはApps Scriptのスクリプトプロパティで管理します。スクリプトを共有すると編集者がこれらにアクセスできるため、管理者は編集権限を限定します。パスワードを本ツールが収集することはありません。

保存期間と削除

日付別の記録は、本人の履歴管理に必要で、YouTubeの保存条件を満たす間だけ保持します。認証が有効かを日次取得時に確認します。取得日時を明示し、過去の数値を現在値として表示しません。

本人はNotion内の記録を削除でき、運営者に削除を依頼することもできます。削除依頼を受けた場合は可能な限り速やかに、7日以内に対応します。本ツール内の記録の削除は、YouTube上の動画やチャンネルを削除する操作ではありません。

接続解除または更新トークンの失効が判明した場合は取得を停止し、関連データについてYouTubeの条件に従って削除を行います。管理者本人がGoogleの設定から接続を取り消した場合も、関連するNotion記録の整理が必要です。自動削除機能が実装されているという説明ではなく、管理者による対応を含みます。

接続解除

Googleアカウントの接続管理からアクセスを取り消せます。Notion側の接続も対象ページの接続設定から解除できます。

GoogleとNotionの取り扱い

本ツールによるGoogle APIから受け取った情報の使用・他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

問い合わせと変更

問い合わせ：GitHubの問い合わせ欄へご連絡ください。問い合わせ内容は公開されるため、メールアドレス、パスワード、確認コード、トークン、その他の秘密情報は書き込まないでください。取り扱う情報や利用目的を変更する場合は説明を更新し、必要な同意を確認します。
